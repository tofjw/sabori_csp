  - 加えて、解を見つけても `best_assignment_` は更新されないため、**解由来の phase は次のリスタートで最深行き詰まりに上書きされる**（solution-guided search が1リスタートで失われる）

- **作業ログを main に集約する運用にした**。1日に複数ブランチを渡り歩くのが常態で、ブランチにログを置くと日単位で追えなくなる。逆にログ以外の成果物は従来どおり作業ブランチに置く
